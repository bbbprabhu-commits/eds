# Expressions D Studio (EDS) — Trichy Website

Static, GitHub-ready landing page for Expressions D Studio. The site uses HTML, Tailwind CDN and local WebP assets; no build step is required.

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `eds-trichy-website`.
2. Upload **all files and folders** in this project (keep `index.html` at the repository root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait for the Pages deployment and open the URL shown there.
6. For a custom domain, configure `edstrichy.com` under Pages and add the DNS records GitHub specifies. Enable HTTPS after DNS verifies.

## Before launch — important checks
- Verify the phone number, branch/service-area details, opening hours, review count and all claims in the page. These details were retained from the supplied draft and should be confirmed before publication.
- The structured LocalBusiness data uses the public domain `https://edstrichy.com/`. Change the canonical, social image, schema and sitemap URLs if the actual domain differs.
- Replace any sample or manually entered ratings/review counts with current, accurate information. Do not describe a Google Business Profile as verified unless that status is confirmed.
- Add your actual Google Maps place link and real branch addresses if you want branch-level local SEO. Do not publish invented street addresses or opening hours.
- Connect the booking form to a real CRM/form backend if you need submissions saved. The current form opens WhatsApp and does not store bookings on a server.
- For Google Ads, add conversion tracking only after you create the correct Google Ads conversion action and consent/privacy setup. Do not paste secrets or API keys into this public repository.
